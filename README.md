# Recursive Number Analyzer

A simple C program that demonstrates recursion through three mathematical operations.

## Features
- **Factorial:** Calculates the factorial of a number.
- **Sum:** Calculates the sum of numbers from 1 to n.
- **Fibonacci:** Generates a Fibonacci sequence.

## Technologies
- C Programming Language
- Recursion

## How to Run

1. Compile the source code:
   ```bash
   gcc main.c -o analyzer
   ```
2. Run the program:
   ```bash
   ./analyzer
   ```
